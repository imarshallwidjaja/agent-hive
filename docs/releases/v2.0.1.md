# Agent Hive v2.0.1

Agent Hive v2.0.1 moves bundled skill materialization into the global OpenCode config directory and makes concurrent cache creation ownership-safe.

## Fixed

- Bundled Hive skills now materialize under `agent-hive/generated/opencode-skills/` in the global OpenCode config directory. The default location is `~/.config/opencode/agent-hive/generated/opencode-skills/`; `OPENCODE_CONFIG_DIR` or `XDG_CONFIG_HOME` can select a different config root.
- Cache identity is computed from the staged tree's relative paths, entry types, file contents, symlink targets, and mode bits. Changes to support files or directory structure therefore produce a different content-addressed destination.
- Each staged `SKILL.md` is reparsed before storage. Its skill name must match the bundled name discovered at startup; changes to its description or body are accepted.
- Concurrent materializations use UUID-owned staging directories and remove only the staging directory they created. If another materialization creates the same content-addressed destination first, the later operation accepts that destination after its rename race; this also covers Windows `EPERM` when the destination now exists.

## Upgrade

- No config migration is required. Legacy project-local generated skill paths are ignored or filtered, but existing directories are not deleted. Remove them after older Agent Hive installations no longer need them.
