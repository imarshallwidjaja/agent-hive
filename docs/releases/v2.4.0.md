# Agent Hive v2.4.0

Agent Hive v2.4.0 introduces operator constraint propagation via `hive_constraints_set`, selects custom Scouts by descriptor rather than hardcoded identifiers, and normalizes review task dispatch across dash and vulnerability review lanes.

## Added

- `hive_constraints_set` stores verbatim operator constraint text on calling orchestrator sessions (Hive, Swarm, Architect, Hive Builder) and automatically injects it under `## Standing Constraints (operator, session-wide)` into every delegated `task()` prompt and generated `worker-prompt.md`.
- Standing constraints propagate across subagent boundaries: task-created architect child sessions fall back one level to the parent register, compaction replay preserves standing constraints, and reviewer and worker prompts acknowledge constraints while reporting conflicts with plan-declared task requirements. Empty string clears the register, and inputs exceeding 8000 characters are rejected.

## Fixed

- The `parallel-exploration` skill now selects scout-derived custom subagents by matching their description against the domain or workflow need, rather than relying on a hardcoded operator-local `scout-researcher-capable` name.
- Review task dispatch normalizes omitted background mode to blocking across dash and vulnerability review lanes while preserving retryable authorization when dispatches are invalid.

## Upgrade

- Update `oc-arkive` to `2.4.0` through the normal OpenCode plugin installation flow.
- No Agent Hive configuration, feature data, or project-local repository-manifest migration is required.
- Restart OpenCode after updating so config-time plugin and guidance changes take effect. If OpenCode uses a cached plugin package, update that cached package before restarting.

## Release

- Tagged `v2.4.0` pushes publish `oc-arkive` to npm through Trusted Publishing, attach `vscode-arkive.vsix` to the GitHub Release, and use this file as the release body.
- Release artifacts carry version `2.4.0` across the root, `hive-core`, `oc-arkive`, and `vscode-arkive` manifests, both lockfiles, and the generated OpenCode plugin manifest.
