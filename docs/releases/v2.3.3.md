# Agent Hive v2.3.3

Agent Hive v2.3.3 adds a general-purpose alignment workflow, makes built-in and custom subagent routing explicit, and applies one shared fail-closed runtime boundary to dash and vulnerability reviews.

## Added

- `/grill <context>` researches material facts and asks one material question per turn until the operator confirms explicit alignment. `/interview <idea>` now uses the same interaction engine with implementation-oriented questions and prepares context for the separate `/implementation-brief` command. Neither command automatically plans, implements, or starts follow-on work.

## Changed

- `/dash-review` and `/vuln-review` now use shared deterministic source resolution, provenance, invocation authority, workspace lifecycle rules, and exact caller, role, tool, and task-target policies. Scope capture uses `hive_git_snapshot` as its sole Git object check, review materialization remains fingerprint-bound, and invalid authority, lifecycle drift, or unavailable integrity evidence fails closed.
- An exact safe GitHub pull-request URL may trigger one bounded, hostname-pinned `gh api` metadata request. Missing or failed provider lookup falls back directly to a dirty-aware local snapshot; resolved metadata retries locally only when every selected repository fails with matching missing base/head object IDs. Other failure classes do not widen scope or authorize fallback.

## Fixed

- Built-in callable subagents now retain comparable default routing descriptions and remain preferred when no configured custom overlay is a closer match. Primary agents select custom specialists autonomously from task fit, while candidate-specific restrictions, including explicit operator naming, remain enforced. Configured descriptions can override seven callable base agents and fall back to the canonical description when cleared.

## Upgrade

- Update `oc-arkive` to `2.3.3` through the normal OpenCode plugin installation flow.
- No Agent Hive configuration, data, or project-local repository-manifest migration is required.
- Restart OpenCode after updating so config-time plugin changes take effect. If OpenCode uses a cached plugin package, update that cached package before restarting.

## Release

- Tagged `v2.3.3` pushes publish `oc-arkive` to npm through Trusted Publishing, attach `vscode-arkive.vsix` to the GitHub Release, and use this file as the release body.
