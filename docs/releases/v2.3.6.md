# Agent Hive v2.3.6

Agent Hive v2.3.6 tightens test-invariant placement, inlines debugging guidance, finishes Hive plan execution through verification plus merge, and skips redundant brainstorming when corrective feedback is already concrete.

## Changed

- Engineering Judgment now places each test invariant in one owning layer and that layer's existing canonical suite in the same change. Later leftover test-cleanup passes are not the default.
- `test-driven-development` names the invariant and owning layer in RED, folds duplicate coverage in REFACTOR, and uses a placement decision order instead of leaving extra files for later cleanup.
- `systematic-debugging` inlines downstream-symptom and hidden-write tracing in the root-cause phase. Companion files are no longer referenced.
- `executing-plans` finishes through verification plus Hive merge (`hive_merge`, typically via `hive-helper` squash). It does not present a generic merge, pull-request, keep, or discard menu.

## Fixed

- `brainstorming` skips ordinary design dialogue when the operator names the wrong behavior, the desired behavior, the affected artifact, and the correction direction. Planning, isolation, testing, and verification gates still apply. Bare bug reports and vague feature requests stay on the ordinary brainstorming path.

## Upgrade

- Update `oc-arkive` to `2.3.6` through the normal OpenCode plugin installation flow.
- No Agent Hive configuration, feature data, or project-local repository-manifest migration is required.
- Restart OpenCode after updating so config-time plugin and guidance changes take effect. If OpenCode uses a cached plugin package, update that cached package before restarting.

## Release

- Tagged `v2.3.6` pushes publish `oc-arkive` to npm through Trusted Publishing, attach `vscode-arkive.vsix` to the GitHub Release, and use this file as the release body.
- Release artifacts carry version `2.3.6` across the root, `hive-core`, `oc-arkive`, and `vscode-arkive` manifests, both lockfiles, and the generated OpenCode plugin manifest.
