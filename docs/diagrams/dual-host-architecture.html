Architecture

One package, two OpenCode hosts

Each OpenCode generation loads its own entry from oc-arkive. Both entries run the same Hive operations, role policy and trace engine. Each host gets its own adapter, and prompts and skills render with that host's profile.

The v1 entry is src/runtime.ts, and the v2 adapter under src/v2/ is imported only when a v2 host activates the plugin. The shared modules are src/runtime/hive-tools.ts, hive-services.ts, role-policy.ts, host-profile.ts and src/trace/engine.ts. Switching a project between hosts means quiescing writers first, as described in the Operator Guide's host handover section.
