State ownership

What stays shared when a project changes host

Project domain state under .hive/ carries over between OpenCode v1 and v2. Each host writes its own Hive observation store and needs its own native home. A host never imports the other's observation records.

Feature constraints are stored in each feature directory's constraints.json and stay shared. Session constraints live in a host's observation store, so they do not move to the other host, and neither do native conversations, live workers or selected session routes. Quiesce writers, give the other host its own native home with Hive's configuration in place, start it, then reapply session directives and select the feature again. The Operator Guide's host handover section gives the full procedure.
