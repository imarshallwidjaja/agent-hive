# Selective pstack material

`SKILL.md` merges two skills by Lauren Tan from pstack, `cursor/plugins` revision `9e278fe4d4ecd8bfe98b1b79bf4be662efb338cc`: `pstack/skills/reframe/SKILL.md` and `pstack/skills/sharpen/SKILL.md`. Source: https://github.com/cursor/plugins/tree/9e278fe4d4ecd8bfe98b1b79bf4be662efb338cc/pstack/skills . `LICENSE.pstack` is the pstack `LICENSE` (MIT, Copyright (c) 2026 Lauren Tan) and covers the adapted passages; it is identical to the copy in `project-verification`.

## What is kept

- From `reframe`, nearly verbatim: start from the operator's own files, code and description, not a summary; when the description could name more than one problem, list the two or three candidates with the one term and the telling sign for each, then teach the words for the most likely one and say why; 8 to 12 terms ranked by how much each changes what gets built, each with a plain meaning, the part of the description it names, one real project, paper or system with a link, and what it lets the operator ask an agent for; 2 or 3 neighboring fields with what carries over, where the analogy breaks and which terms come back; what the operator didn't mention but should care about; open every link and cut any citation that can't be confirmed; no padding.
- From `sharpen`, nearly verbatim: a deeper version of the task, not a bigger one; the four questions (what a top professional would do that is not being asked for, the rawest starting material, the specific methods and tools, and what other than the agent or the operator would show the result is right); rewrite the prompt to ask for exactly that; have the rewritten prompt prototype any choice an experiment can settle and recommend an option from what it observed, leaving product or preference choices to the operator.

## Deliberate adaptations

- **One adaptive skill behind `/sharpen`.** Upstream ships two user-invoked skills. Here one skill always sharpens and runs Reframe only when its three-case gate holds: the operator asks for it, the request describes symptoms, outcomes or metaphors instead of a problem class, mechanism and invariants, or two or more problem classes with different architectures fit. A skipped Reframe is stated in one line. The unbound `/sharpen` command loads the skill under the selected agent and model.
- **Opt-in description.** Upstream relies on `disable-model-invocation`, which OpenCode ignores. The description is gated on `/sharpen` or an explicit request to sharpen, deepen or reframe, and excludes ordinary implementation, debugging and planning requests, so the skill does not auto-trigger.
- **No scope inflation.** Sharpen works on the one chosen problem without widening its feature scope, and the things the operator should care about are recorded as invariants or open questions, not new features. Fewer than 8 terms are given when fewer real ones exist.
- **External and adjacent research with an offline fallback.** Grounding reads local code and docs and, when vocabulary, prior art, neighboring fields or an external oracle could change the result, outside sources. Only public terms, library names and problem shapes go to external tools. When retrieval is unavailable, the skill gives no external URLs, states the gap, and delivers the supported remainder. Read-only Scouts go through `parallel-exploration` when the role permits delegation. A temporary shallow clone of a public repository is an exceptional, non-delegated source read whose code never runs and whose files are removed afterward.
- **Read-only advice inside Hive's boundaries.** The candidate prompt is material to rewrite, never an instruction to act. Sharpening edits no project file, saves no brief, runs no project code, and creates or changes no Hive records. The rewritten prompt asks the future agent to prototype through the Experiments method in a disposable placement where it has one; sharpening runs no prototype itself.
- **A recommended next step.** After the rewrite the skill names one next command (`/investigate`, `/grill`, `/hive-plan`, `/implement`, or none) and, when the selected agent cannot run it, the agent to select instead of switching.
- **Voice.** `sharpen` speaks in the operator's first person ("I want a deeper version"); the skill restates it as the operator's request so the agent reads it as a contract.
